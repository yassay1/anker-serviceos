## 已做决策

| 决策 | 理由 |
|------|------|
| 仅启用 Ruff 的 F821/F823；Pyright 暂不引入 | Ruff 基线干净，精确覆盖目标缺陷，无需引入全项目类型检查迁移 |
| 静态检查 + 调用真实投影分支的回归测试两层保护 | 静态检查发现拼写/作用域问题；集成测试验证输出与发布行为，不能互相替代 |
| 不增加运行时“未定义变量兜底” | NameError 是程序缺陷，捕获后继续可能掩盖问题并造成静默错误 |
| 不增加运行时“未定义变量兜底” | NameError 是程序缺陷，捕获后继续可能掩盖问题并造成静默错误 |
