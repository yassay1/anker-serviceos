## 已做决策

| 决策 | 理由 |
|------|------|
| 只改客户视图，不改 `/desk`、后端业务逻辑与 API 契约 | 完成事件保留在服务端；客服内部进度仍可见 |
| 客户仅显示有实际服务/客户行动含义的状态 | worker 结束不等于服务案例解决；保留等待证据与真实失败反馈 |
| UI 文档按位置拆分：安全/补充信息留在对话，协助入口放在侧栏 | 避免重复卡片，同时保持后端授权和请求恢复语义 |
| 首页与案例页使用现有实现 | 已有布局、接口和视觉验收基础符合参考图，不需重写 | 
| 使用现有 React/CSS/Lucide 和 API Client，不添加依赖 | 继承产品已有视觉系统和契约 |
