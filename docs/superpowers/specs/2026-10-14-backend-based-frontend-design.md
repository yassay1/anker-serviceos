# 基于真实后端的前端适配

沿用用户已确认的现有工程与参考图方向。保留品牌、API、认证、权限、幂等和 SSE；扩展工作台、客户服务及只读设备页面。相比直接搬入独立演示原型，这种方式可以复用已通过的业务路径；只改样式则无法补齐设备数据与窄屏操作，故选择按现有真实契约扩展页面。

1. 会话列表增加本地搜索、状态筛选和明确的加载/空态，不声称搜索整个后端数据库。
2. 桌面维持三栏信息结构并提升密度；手机使用列表/会话/资料切换，保留各会话输入。
3. 公开回复、内部备注、协作模式、任务、草稿和交互卡都来源于实际接口。审阅原因最少三字，与当前后端限制一致。
4. 新增 `/devices` 和 `/devices/:id`，仅使用现有 GET devices/read device/device cases。Device、Case 和 Conversation 保持独立；只展示后端已核验事实，拒绝读取时不展示旧详情。
5. 未实现的附件、外部动作、结果核验不新增操作。业务与生成契约不修改。
6. 测试先复现搜索/手机操作/草稿隔离/设备页的缺失，保留已有冲突回归；CI 增加真实 API+PostgreSQL 的浏览器路径，与 HTTP 受控回归区分。
7. 生成后批量检查桌面、手机、无障碍、空态与错误；一次集中优化后复核，保留截图与范围说明。
