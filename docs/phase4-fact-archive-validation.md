# 阶段 4 Case 来源设备事实归档验收

2026-10-14。新增候选事实可记录 `source_case_id` 与客户端幂等编号；应用服务验证 Case 与 Device 属同客户且已关联。客服核验沿用原有事实状态服务；只有来源 Case 为 `RESOLVED`、事实为 `VERIFIED` 时，客服才能执行归档。归档保留来源、核验人与时间、归档人和时间，撤销仍可追溯。

客户 API 显示来源类型和 Case 编号，但不返回内部客服标识；数据库仍保留原始来源、核验人和撤销记录供授权审计。客服可在设备页录入候选、核验、归档和撤销；候选创建以客户端事实编号处理未知结果重试。
