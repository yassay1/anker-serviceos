## 设计转译

- 优先参考第 04、05 张的桌面客户工作区：会话历史、聊天内容、服务资料各自占据清楚的区域。第 01、02、03 张用来补充不同宽度和页面状态的对照。
- 延续售后通已建立的暖白画布、深蓝文字、服务蓝主操作、轻描边与克制阴影；使用项目现有组件和 token，不引入另一套品牌皮肤。
- 客户界面只呈现客户需要的服务信息和下一步。Worker 生命周期、内部活动、技术修订号不能伪装成案例结论；真人协助入口保持单一、清楚。
- 桌面三栏不能挤压消息可读宽度。平板和手机沿用可访问的列表/对话/资料切换；保留输入内容和键盘操作。
- 这些原图不等于当前所有列出的结构和交互均已实现。当前实现、接口范围及验证情况见[客户会话桌面优先对齐](../../ui-design-guidelines.md#客户会话桌面优先对齐)和项目阶段验收记录。
