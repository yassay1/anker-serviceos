## 用图边界

- 原图仅作内部设计评审素材；按日期分组保留，不覆盖旧版本。新增参考图需记录来源、收到日期和 SHA-256。
- 提取色彩、排版、间距、卡片、导航和信息层级，再用现有 React 页面重建；不将整张截图用作页面背景。
- 图片中的品牌设备、客户姓名、工单号、统计数字、处理进度、诊断结论、维修承诺和按钮效果均为示意，不能复制成真实记录或验收事实。
- 保持一个 Web 应用中的客户与客服视图。新增入口和操作须对照产品文档、实际业务 API 与生成类型；未实现能力不做可点击的假成功流程。
- 外部操作、公开 AI 回复、事实核验及协作模式的权限由后端应用服务控制。截图不是业务规则或接口契约。
- 逐页验收真实成功、加载、空态、失败和权限不足状态；能力完成情况以[开发计划](../development-plan.md)和阶段验收记录为准。
