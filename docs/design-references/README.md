## 用图时的边界

- 优先提取色彩、排版、间距、卡片、导航和信息层级，再按现有 React 页面重建；不要把整张截图当成页面背景。
- 图片中的品牌设备、客户姓名、工单号、统计数字、处理进度、AI 诊断结论、维修承诺和按钮效果都是示意。界面只展示后端真实提供且当前用户有权查看的数据。
- 当前保持一个 Web 应用中的客户与客服视图。新增入口和操作须先对照产品文档、实际业务 API 和生成的前端类型；未实现能力不做可点击的假成功流程。
- 外部操作、公开 AI 回复、事实核验及协作模式的权限由后端应用服务控制。图片不作为业务规则或接口契约。

视觉实现建议先统一设计变量和共享组件，再分别完成 `/support`、`/desk` 的响应式布局；按真实成功、加载、空态、失败、权限不足状态逐页验收。具体能力的完成状态只由[开发计划](../development-plan.md)和阶段验收记录确认。
